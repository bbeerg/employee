# ระบบจัดการข้อมูลการปฏิบัติงานของพนักงาน

##  ภาพรวมระบบ 

ระบบสำหรับบันทึกเวลาเข้า-ออกงานของพนักงาน พร้อมระบบจัดการหลังบ้าน สำหรับตรวจสอบ สรุปผล และจัดการข้อมูลพนักงาน โดยเน้นการแสดงผลภาพรวมบน Dashboard เป็นหลัก

##  ส่วนของพนักงาน

1. บันทึกเวลาเข้า-ออกงาน:
   - พนักงานต้องเข้าสู่ระบบ (Login) เพื่อกดปุ่มเข้างาน และออกงาน
   - ระบบจะบันทึก Timestamp ตามเวลาจริง ณ วินาทีที่กดปุ่ม
   - สามารถระบุ "หมายเหตุ" เพิ่มเติมได้ (แสดงเป็น Pop-up ให้กดยืนยันหรือยกเลิก)

2. จัดการโปรไฟล์ส่วนตัว:
   - ดูข้อมูลโปรไฟล์ของตนเองได้ (เช่น รหัสพนักงาน, ชื่อ, แผนก/ตำแหน่ง)
   - สามารถออกจากระบบ (Logout) ได้

3. การจัดการบัญชีผู้ใช้:
   -ไม่อนุญาต ให้พนักงานสมัครสมาชิกเอง
   - ผู้ดูแลระบบ จะเป็นผู้สร้างบัญชี และส่งมอบอีเมล/รหัสผ่านให้พนักงานเข้าใช้งาน

##  ส่วนของผู้ดูแลระบบ

1. ระบบเข้าสู่ระบบ:
   - เข้าใช้งานด้วยอีเมลและรหัสผ่านของผู้ดูแลระบบ

2. แดชบอร์ดภาพรวม:
   - แสดงสถิติและภาพรวมการทำงานของพนักงานทั้งหมด เช่น จำนวนคนมาทำงาน, คนมาสาย, คนขาดงาน

3. การออกรายงาน (Import / Export):
   - สามารถ Import ข้อมูลพนักงานเบื้องต้นผ่านไฟล์ CSV ได้
   - สามารถ Export รายงานการเข้า-ออกงานเป็นไฟล์ PDF โดยกำหนดช่วงเวลาได้

4. การจัดการพนักงาน:
   - สามารถ เพิ่ม (Create), ดูข้อมูล (Read), แก้ไข (Update) และ ลบ (Delete) ข้อมูลพนักงานใหม่ได้
   - หมายเหตุ: การลบพนักงานจะใช้รูปแบบ Soft Delete เพื่อไม่ให้กระทบประวัติการทำงานเดิม

##  โครงสร้างฐานข้อมูล 

ระบบประกอบด้วย 6 ตารางหลัก ดังนี้:

### 1. ตาราง `admins` (ผู้ดูแลระบบ)
| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `admin_id` | VARCHAR(20) | Primary Key | รหัสผู้ดูแลระบบ |
| `email` | VARCHAR(100) | Unique, Not Null | อีเมล |
| `password_hash` | VARCHAR(255) | Not Null | รหัสผ่าน (แฮช) |
| `role` | VARCHAR(20) | Default 'admin' | สิทธิ์การใช้งาน |

### 2. ตาราง `departments` (แผนก)
| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `department_id` | INT | PK, Auto Increment | รหัสแผนก |
| `department_name` | VARCHAR(50) | Not Null, Unique | ชื่อแผนก (เช่น ไอที, การเงิน) |

### 3. ตาราง `positions` (ตำแหน่ง)
| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `position_id` | INT | PK, Auto Increment | รหัสตำแหน่ง |
| `position_name` | VARCHAR(50) | Not Null | ชื่อตำแหน่ง |
| `department_id` | INT | FK (ON DELETE CASCADE) | รหัสแผนกที่สังกัด (`departments.department_id`) |

### 4. ตาราง `employees` (พนักงาน)
| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `employee_id` | VARCHAR(20) | Primary Key | รหัสพนักงาน |
| `first_name` | VARCHAR(50) | Not Null | ชื่อ |
| `last_name` | VARCHAR(50) | Not Null | นามสกุล |
| `email` | VARCHAR(100) | Unique, Not Null | อีเมล |
| `password_hash` | VARCHAR(255) | Not Null | รหัสผ่าน (แฮช) |
| `position_id` | INT | Foreign Key | รหัสตำแหน่ง (`positions.position_id`) |
| `is_active` | TINYINT(1) | Not Null, Default 1 | สถานะพนักงาน (1 = ใช้งานอยู่, 0 = ถูกลบ/ลาออก) |

### 5. ตาราง `attendance_logs` (การบันทึกเวลาเข้า-ออกงาน)
*หมายเหตุ: ใช้ Composite Key (`employee_id` + `work_date`) ทำให้บันทึกได้ 1 แถวต่อคนต่อวัน และใช้ `ON DELETE RESTRICT` เพื่อป้องกันประวัติหาย*

| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `employee_id` | VARCHAR(20) | PK, FK (ON DELETE RESTRICT) | รหัสพนักงาน (`employees.employee_id`) |
| `work_date` | DATE | Primary Key | วันที่บันทึก |
| `shift_start_time` | TIME | Default '09:00:00' | เวลาเข้างานตามตาราง |
| `shift_end_time` | TIME | Default '18:00:00' | เวลาออกงานตามตาราง |
| `check_in_time` | DATETIME | Nullable | เวลาเข้างานจริง |
| `check_out_time` | DATETIME | Nullable | เวลาออกงานจริง |
| `remark` | TEXT | Nullable | หมายเหตุ |
| `ot_hours` | DECIMAL(4,2) | Default 0.00 | ชั่วโมง OT |
| `total_work_hours` | DECIMAL(4,2) | Default 0.00 | รวมชั่วโมงทำงานต่อวัน |
| `photo_url` | VARCHAR(255) | Nullable | พาธ/URL รูปถ่าย |
| `work_status` | VARCHAR(20) | Default 'มา' | สถานะ (มา, สาย, ลา, ขาด) |

### 6. ตาราง `holidays` (วันหยุด)
*หมายเหตุ: มี `UNIQUE` ที่ `holiday_date` เพื่อป้องกันการเพิ่มวันหยุดซ้ำในวันเดียวกัน*

| ชื่อฟิลด์ | ประเภทข้อมูล | ข้อกำหนด | คำอธิบาย |
| :--- | :--- | :--- | :--- |
| `holiday_id` | VARCHAR(20) | Primary Key | รหัสวันหยุด |
| `holiday_name` | VARCHAR(100) | Not Null | ชื่อวันหยุด |
| `holiday_date` | DATE | Not Null, Unique | วันที่หยุด |
